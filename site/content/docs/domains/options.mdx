Price a single option or a whole chain. Facades such as `blackScholes` return plain numbers and explain themselves on request; `option` and `engines` select a model explicitly; `impliedVolatility` inverts a price. Exotic payoffs (barriers, digitals, Asians, lookbacks, cliquets, autocallables and more) are included, each with the same explicit units.
