---
title: 'Technical analysis'
description: 'Hundreds of registered indicators with explicit warmup, streaming state, snapshots and a TA-Lib compatibility matrix.'
---

Every indicator is a function over an array that returns an aligned array, with `NaN` during warmup. The same indicators stream bar by bar, snapshot and restore their state, and compose into signals and feature pipelines. Candlestick patterns, pivots, Fibonacci levels and alternative bar types are included.
