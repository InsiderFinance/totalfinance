# Evidence provenance

`release-dry-run-0.0.1-rehearsal.json` is an immutable historical rehearsal from before the
standalone repository and brand migration. Its old package names, source commit and hashes
describe the bytes tested at that time. They are **not approval** to publish TotalFinance, and
they are not a manifest for the current source. Preserve the record unchanged rather than
substituting new names under old hashes.

New release evidence must come from the exact committed TotalFinance release candidate via
the [release runbook](../runbooks/release.md), followed by separately authorized publication
and a successful public-registry smoke. See the [migration record](../specs/standalone-totalfinance-migration.md).
